# relvista/.github

Organisation profile and shared GitHub files for [relvista](https://github.com/relvista).

- `profile/README.md` is shown on https://github.com/relvista.
- `profile/assets/` holds the logo set: avatar, banner, social preview, favicon and wordmarks (light and dark). The wordmark uses Manrope (SIL Open Font License, see `MANROPE-OFL.txt`), converted to outlines.
